## 1. 戦略の核（2026-07-17 施主指摘で訂正）
> **CTRが低い本質＝pos6-7で、同質の競合サイトが上位（pos1-5）を占めているから。論点は「順位上昇」**。CTR/スニペット最適化では解決しない。

### 競合ギャップ分析（「カーブス 料金」SERP実査）
- 上位＝FitMap（口コミ500人）/大阪ガスDaigas（大手ドメイン）/CACHIマガ（料金一覧表）/Getfit（【2026最新】料金・入会金無料キャンペーン）/みん評（口コミ2,527件）。**全員が具体的な料金数値を掲載**（入会金16,500円・月会費6,820〜7,920円）。
- **当サイトcurves記事の致命的欠落**：①**「月会費」が"公式サイト参照"で数値未記載**＝「料金」クエリに答えていない（33,792imp/pos6.7で埋もれる構造的理由）②FAQ完全欠落 ③確認日不明確・キャンペーン情報なし。（強み＝8,000字・口コミ15事例・5社料金比較表・継続率/会員数/店舗数の数値根拠）

### 順位上昇の実行論点
1. **クエリ意図への直答＝料金の具体数値を確認日付き実データで**（"公式参照"をやめる）。
2. **独自資産でInformation Gain＝約2,000店舗の実店舗DB**。競合は全国まとめ記事＝「店舗別の料金・アクセス・女性専用有無」で"その店でしか書けない情報"を出せる＝**同質競合が構造的に真似できない堀**。
3. **FAQ＋FAQPage構造化**でリッチリザルト＆網羅性。
4. **鮮度**（確認日＋定期再実査）。
5. **内部リンク権威集中**（12,769ページから対象記事へ）。

## 2. 実行計画（優先順）

### P0【最速・最大回収】高表示ブランド記事のCTR最適化
対象：curves / fit24 / chocozap / beyond / 247workout / the-personal-gym 等（表示上位10本）。
- **titleを情報型指名クエリに一致**：「◯◯の料金・口コミ・評判は？【2026年】月額◯円〜／デメリットも正直解説」型。特に「◯◯ 料金」意図に**具体的な最安料金を数値でtitle/descに前出し**（カーブス料金33,792imp・チョコザップ料金11,223impがCTR0.3-0.4%＝ここが最大の穴）。
- **meta descriptionに数値と結論**（月額・入会金・回数・「勧誘は？」等の不安直答）を入れてスニペットで差別化。
- **構造化データ**：FAQPage / BreadcrumbList でリッチリザルト獲得。料金表・口コミ傾向を上部に。
- KPI：上位10本の平均CTRを0.9%→2.5%へ → **月+3,000〜5,000click規模**。

### P1【質の底上げ】CTRの型を全ブランド記事へ横展開
P0で効いたtitle/desc/構造化の型を、残りブランド記事（229＋）へ展開。勝ちクエリ（口コミ/評判/料金/やばい/デメリット/2026）を軸に統一。

### P2【地域軸の拡張】エリア×パーソナルジム記事の強化
- pref/city/station記事はCTR高（1.7-2.8%）だが pos10-22 に滞留 → **上位化で刈れる**。
- 「◯◯（地名）パーソナルジム」「◯◯駅 パーソナルジム」需要（横浜・郡山・柏・船橋等が既に表示）を、地域固有情報（相場・駅近・女性専用有無）で厚くして page1 へ。
- 地域は大手ブランドより競合が薄く、CVにも近い。

### P3【収益化・CV導線】
- **B2B（掲載問い合わせ）**：完成した /contact フォームへの導線を、地域記事・ブランド記事・比較表から強化（事業者向け「掲載希望はこちら」）。
- **アフィリ/送客**：BEYOND・RIZAP等の提携済みCTAを高CTR化した記事に確実に配置。無料カウンセリング動線を結論box直下・料金表直下に。
- 検索意図（料金/口コミ）→比較→カウンセリング予約/掲載問い合わせ を全記事で貫通。

### P4【E-E-A-T・鮮度】
- **料金は変動が命** → 確認日明記＋定期再実査を運用化（料金クエリで勝つ前提条件）。
- 口コミは出典付きのみ・自作評点なし（既存方針を徹底）。運営者情報・比較根拠を明示。

## 3. 測定と運用
- 主指標：**総click（現3,612/28日）とCTR**。P0効果は1〜2週でGSC判定。
- 勝ち型（CTRが上がったtitle/desc/構造化）を横展開。料金クエリのCTR改善を最優先KPIに。
- 目標目安：P0で28日5,000〜7,000click、P0+P1+P2で 10,000click超を狙う（表示35.7万の受け皿がある）。
